Inequalities (Coded & Direct)

Don’t memorise sign tables — see the chain. Every statement like P ≥ Q > R = S places letters on a number line. A conclusion is judged by asking one question: in which positions can these two letters still end up? If every possibility agrees, it follows; if none agrees, it is false; otherwise it is doubtful.

See the chain on a number line

Bigger sits to the right. “=” means two letters share one slot. Pick a letter to see who is bigger, smaller, equal — or unrelated to it.

Predict first — which sign survives?

Decide before the chain is drawn. Then check your picture against it.

Statement: P ≥ Q > R = S

How do P and S compare?

Walk it left to right: P ≥ Q (gap may be 0) → Q > R (gap is real, > 0) → R = S (gap is 0). Total gap = 0 + (something positive) + 0 = positive. So P > S, and “P = S” is impossible.

Either / Or — when two doubts add up to a certainty

Two letters can be in only three relations: <, =, >. See which ones each conclusion covers.

Blue = only conclusion I is true there. Purple = only II. Amber = both. Red dashed = possible, but neither conclusion covers it — so “Neither follows”. Grey = the statement already rules that picture out.

Rules that fall out of the chain

Each rule is just what you already saw on the line — now written down.

Gaps add up

≥ ≥ ≥ → ≥   ≥ > ≥ → >

In an unbroken one-direction chain, one strict link makes the whole relation strict. All ≥ gives only ≥ (equality stays possible). “=” adds nothing.

Direction must not turn

P > Q ≤ R → no P–R link

A valley (> then ≤) or a peak (< then ≥) breaks the chain. The two ends are on different branches — every position is still possible.

A loop of ≥ means =

H ≥ J ≥ K ≥ H → H = J = K

If you can walk from H down to K and from K back up to H without a strict link, they must share one slot.

Judging one conclusion

true · false · doubtful

List the relations still possible for the two letters. All fit → follows. None fit → false. Some fit → cannot be determined.

Either / Or

≥ with < · > with ≤ · = with ≠

Same two letters, both individually doubtful, and together they cover <, = and >. Then “Either I or II”. If they leave out “=” (like > and <), it is “Neither”.

Coded symbols

@ © $ % # → decode first

Translate every symbol using this question’s legend, then draw the chain. Legends change between questions — never carry one over.

Opposites: “not P > Q” is P ≤ Q; “not P ≥ Q” is P < Q. That is why P ≥ Q and P < Q are complementary.

Exam shortcuts

Speed card for the exam hall. Read after Practice — then race the timed set.

  • Use

    Draw the chain

    P > Q ≥ R = S → one line. Conclusions need a path of links.

  • Trap

    Valley / peak

    Opposite signs from a middle term → unordered ends → cannot say / either-or.

  • Check

    Either-Or

    Complementary pair covering <, =, > with no leftover case.

  • Speed

    Coded symbols

    Decode the legend first on paper — then treat as normal inequalities.
