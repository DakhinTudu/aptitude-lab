3. Core Exam Rules & Fast Shortcuts

Rules, boundaries, and when shortcuts are mathematically valid.

The Multiplier Method

Instead of calculating the percentage and adding it separately, multiply directly by $(1 \pm \frac{P}{100})$:

  • Increase by 15% $\implies$ multiply by 1.15
  • Decrease by 20% $\implies$ multiply by 0.80
  • Increase by 125% $\implies$ multiply by 2.25

The Base Shift Rule (Reversals)

If $A$ is $x\%$ more than $B$, then $B$ is less than $A$ by:

$\text{Percentage Less} = \frac{x}{100 + x} \times 100\%$

*Condition:* Valid when returning to the original base (e.g. price rises by 25%, consumption must fall by $\frac{25}{125} = 20\%$ to keep expenditure constant).

Successive Percentage Changes

If a quantity changes by $a\%$ followed by $b\%$, the net effective change is:

$\text{Net Change} = a + b + \frac{a \times b}{100}\%$

*Caution:* Use negative signs for decreases. Valid only when $b$ is applied sequentially to the result of $a$, NOT on two separate quantities.
