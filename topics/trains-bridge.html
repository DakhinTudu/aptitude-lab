Understand: what distance must the train cover?

Clear means the tail has passed. Pole/man ≈ zero length → only train length. Platform has length → train + platform. See the green distance bar — that is time × speed.

Exam shortcuts

Speed card for the exam hall. Read after Practice — then race the timed set.

  • Use

    Distance = L_t + L_b

    Cross time = (train + bridge) / speed. Pole/man: bridge = 0 → only L_t.

  • Trap

    Forget train length

    Crossing a bridge is never "bridge ÷ speed" alone — tail must clear.

  • Check

    Units first

    km/h → m/s: ×5/18. m/s → km/h: ×18/5. Do this before arithmetic.

  • Speed

    Relative speed

    Same direction: |v₁−v₂|. Opposite: v₁+v₂. Then same (L₁+L₂)/v_rel.
