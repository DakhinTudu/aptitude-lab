Pattern signatures — what the shape tells you

Read the shape of the D₁ / D₂ bands like a diagnostic chart.

Flat D₁ band → Arithmetic

All bars equal height. e.g. 5, 8, 11, 14 → +3 each step.

Climbing D₁ + flat D₂ → Quadratic

D₁ bars rise steadily. D₂ band is a flat line. e.g. 3, 7, 13, 21 → D₁ = 4, 6, 8; D₂ = 2.

Prime-shaped D₁ → Primes

D₁ = 2, 3, 5, 7 → next is 11, not 9. Beware if D₁ starts with +2.

Ratios matter → Multiplier

If D₁ looks chaotic, check term-to-term ratios. They may form a clean ladder (+0.5, +1, ×2…).

Zigzag D₁ → Interleaved tracks

Two independent sequences glued together. The track split view makes it visible.

Exam shortcuts

Speed card for the exam hall. Read after Practice — then race the timed set.

  • Use

    Diff pyramid first

    Write 1st differences; if not constant, 2nd. Alternating / ×k+c next.

  • Trap

    Prime vs odd

    Don't force +2,+2 when the pattern is primes or ×n+1.

  • Check

    Two tracks

    Odd/even positions often independent — split before combining.

  • Speed

    Letter series

    Position in alphabet (A=1). ±k or reverse (A↔Z) are the usual two.
