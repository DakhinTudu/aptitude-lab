Conversion rules laboratory

Which statements can be reversed? Only some. This is the foundation of syllogism shortcuts.

—
—
StatementReversible toValid conversion
All A are BSome B are A ✓All A are B → Some B are A (traditional convention)
No A is BNo B is A ✓No A is B ⇔ No B is A (symmetric)
Some A are BSome B are A ✓Some A are B ⇔ Some B are A (symmetric)
Some A are not B✗ Cannot reverse"Some A not B" says nothing about B vs A
Only A are BAll B are A ✓"Only A are B" = "All B are A" — reversed is one-way
Only a few A are BSome A are B; Some A are not BTwo facts at once, neither reversible to B→A
⚠️ Convention note: Competitive exams typically follow the traditional convention: "All A are B" implies "Some B are A" (assumes A is non-empty). Some modern logic courses require A to exist separately. This lab uses the exam convention consistently.

Translates to All B are A. Direction is critical. "Only surgeons are doctors" = "All doctors are surgeons".
Only a few A are B

Exam convention: Some A are B AND Some A are not B. Same as "only a few" in most papers.

= Majority. Some are, and possibly some aren't. Means "More than half". Typically not a definite conclusion source.

Either-Or — 3-condition AND gate

All three conditions must hold. Toggle and watch the verdict.

Either/Or does NOT apply
✓ Valid complementary pairs
Some A are B + No A is B
All A are B + Some A are not B
✗ NOT complementary (trap)
All A are B + No A is B — both can be false when only some A are B. Never use as either-or.

Why "All + No" fails: if only some cats are dogs, then "All cats are dogs" is false AND "No cats are dogs" is false. Both fail together — no coverage.

Only-a-few deep-dive

"Only a few" ≠ "few" ≠ "only" ≠ "most". Each has a specific direction and hidden meaning.

—
—
⚠️ Directional trap: "Only a few A are B" restricts the A side (some A are inside B, some A outside B). It does NOT restrict B — all of B might be inside A. Students frequently reverse this.

Reverse syllogism laboratory

Given conclusions, which statement set produces them? This is the banking-exam advanced pattern.

—
—
Reverse reasoning
Goal-first method
Start from the conclusion. What premises would force it? Look for chains ending at the target.
Some A are C needed
Some statement chain like Some A are B, All B are C would give it. Test each option.
No B is C needed
Either direct ("No B is C") or via chain (All B are D, No D is C).
Eliminate fast
If a statement set has a statement that contradicts the conclusion, eliminate immediately.

⚠️ Critical distinction: "Does not follow" ≠ "is false." If premises allow both truth and falsity, the conclusion "does not follow" but is not false. Only when a conclusion fails in every valid model is it false. Most exams use "does not follow" for the mixed case.

Exam shortcuts

Speed card for the exam hall.

Definite vs possible
Definite = true in every valid model. Possibility = true in at least one.
Some + Some
Some A are B + Some B are C ⇏ Some A are C. Zero definite connection.
Either-or
All 3 conditions: both doubtful, same terms, complementary pair. Only Some+No or All+SomeNot.
Only a few
Some A are B AND Some A are not B. Direction: restricts A, not B.
Only A are B
All B are A. Direction reverses — trap!
Chain rules
All+All→All. All+No→No. Some+All→Some. Some+No→SomeNot. Some+Some→nothing.
Conversion
All reversible→Some reversed. No and Some symmetric. SomeNot not reversible.
Doesn't follow ≠ false
Not-follow means "unknown, could be true or false". False means "impossible in every model".
Reverse syllogism
Start from conclusion. Find premises that produce it. Eliminate statement sets that contradict.
Min intersection
For Some A are B: min |A∩B| = max(0, |A|+|B|−|U|) or simply ≥ 1. For All A are B: min = |A|.
