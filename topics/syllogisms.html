The verdict matrix — why "one diagram" lies

Each column is a valid model. A conclusion is definite only if it's true in every column. Otherwise it's only possible (or impossible).

Reading the matrix: A row of all ✓ across every model column means definite true. A row with mixed ✓/✗ means only possible — true in some models, false in others. A row of all ✗ means impossible.

Understand: definite vs possibility

Either/Or — the 3-condition AND gate

All three must hold for Either/Or to apply. Toggle them and watch the verdict.

Either/Or does NOT apply

Common trap: All + No looks like a complementary pair but both can be false at the same time — e.g., "All cats are dogs" and "No cats are dogs" are both false when only some cats are dogs. So All + No is never valid Either/Or.

Exam shortcuts

Speed card for the exam hall. Read after Practice — then race the timed set.

  • Use

    Definite vs possible

    Definite = true in every valid diagram. Possibility = true in at least one.

  • Trap

    Some + Some

    Some A are B + Some B are C ⇏ Some A are C.

  • Check

    Either-Or

    Only when the pair is complementary and both can't fail together — else "neither".

  • Speed

    Only a few A are B

    = Some A are B + Some A are not B. Direction is fixed.
