Predict first — the Chinese-coding trap

Decide before you reveal. Then the map in the lab above will back you up.

In a code: “sky blue” = “ta no” and “blue sea” = “zi ta”

What is the code for sea?

Working: “blue” is the only word in both statements, and “ta” is the only code in both → blue = ta. In statement 1, sky = no. In statement 2, once blue = ta is removed, sea = zi. Answer: zi. Matching by position would have given “ta” — the order of codes is not the order of words.

Rules that fall out of the pictures

Now that you have seen the slide, the mirror and the shared word, the formulas are just bookkeeping.

Shift

new = ((p + k − 1) mod 26) + 1

p is the letter's number (A=1…Z=26). Passing Z wraps to A. Decode by shifting by −k.

Mirror (A↔Z)

new = 27 − p

Pairs are A–Z, B–Y, …, M–N. Every pair sums to 27. Applying it twice returns the original.

Find k from one pair

k = (p_code − p_plain) mod 26

Check one more letter to be sure the whole word follows the same k. A k of −2 is the same as +24.

Chinese coding

shared word ⇔ shared code

A word in two statements pairs with the code those statements share. Then eliminate matched pairs. No shared word → cannot be determined.

  • Direction. Check whether the code moved the letter forward or backward before applying it to a new word.
  • Wrap. X, Y, Z (and A, B, C going backward) wrap around — never run off the alphabet.
  • Mirror ≠ shift by 13. The mirror reverses direction; a shift of 13 does not.
  • Order of operations. “Mirror then shift” and “shift then mirror” give different words.
