Predict first — the Chinese-coding trap

Decide before you reveal. Then the map in Section 10 backs you up.

“sky blue” = “ta no” and “blue sea” = “zi ta”

What is the code for sea?

Working: "blue" is in both statements, "ta" is in both → blue = ta. Then sky = no (statement 1), sea = zi (statement 2). Answer: zi. Position matching would have given ta — codes are not in word order.

Exam shortcuts

Speed card for the exam hall.

Infer the shift
First letter delta → verify with 2nd letter. Progressive: +1, +2, +3.
Mirror ≠ reverse
A↔Z changes each letter in place. Reverse changes positions.
Chinese coding
Shared word ↔ shared code. Never match by position.
Number code
Test sum first. If sum doesn't fit, try product / reverse / squares.
Matrix
Row = ⌈p/5⌉, Col = ((p−1) mod 5) + 1. A=(1,1), F=(2,1), U=(5,1).
Conditional
Build the rule table first. Apply per letter, then position rules.
Order matters
Mirror-then-shift ≠ shift-then-mirror. Follow stated order.
Ambiguity
If two rules fit, and one is more specific, use the specific one.
Cannot be determined
If no shared word/code, or symbol missing → CBD is often correct.
